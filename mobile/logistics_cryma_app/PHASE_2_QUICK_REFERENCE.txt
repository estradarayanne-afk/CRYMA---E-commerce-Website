  GET /api/admin/stats               Get dashboard stats

================================================================================
VALIDATION RULES
================================================================================

TEXT FIELD LIMITS:      Max 50 characters (all text fields)
NAMES:                  Unicode letters/spaces/hyphens/apostrophes only
EMAIL:                  Valid format, unique, max 100 chars, normalized lowercase
PHONE:                  Philippine format (09XXXXXXXXX or +639XXXXXXXXX)
                        Normalized to +639XXXXXXXXX
PASSWORD:               Min 8 chars, max 128 chars
                        Must include: uppercase, lowercase, number
                        Hashed with bcrypt (12 rounds)
TIN:                    Exactly 9 digits
LICENSE PHOTO:          JPG/PNG only, max 5 MB
VEHICLE TYPE:           Enum (Motorcycle, Bicycle, Tricycle, Car/Van, Truck)

================================================================================
ACCOUNT STATES
================================================================================

PENDING:                New rider, awaiting admin approval
                        Can check status via API
                        Limited access
ACTIVE:                 Approved by admin
                        Full access to features
REJECTED:               Admin rejected registration
                        Cannot log in
