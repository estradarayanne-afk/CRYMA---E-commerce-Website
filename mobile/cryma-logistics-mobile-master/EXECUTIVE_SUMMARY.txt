DATABASE SCHEMA (8 TABLES)
================================================================================

users (53 columns)
├─ Rider and admin accounts
├─ Profile data (name, phone, TIN)
├─ Address information (7-level geographic hierarchy)
├─ Vehicle details (type, make, model, color, plate)
├─ License information (number, expiry, classification)
├─ Photo storage (approved and pending paths)
└─ Account status tracking (pending, active, rejected)

orders (13 columns)
├─ Order details (item name, description)
├─ Parties (sender, recipient)
├─ Locations (pickup, destination)
├─ Status tracking (5 states: FOR_PICKUP, ON_TRANSIT, etc.)
├─ Rider assignment
└─ QR code for delivery verification

reports (8 columns)
├─ Citations and warnings for riders
├─ Reason and description
├─ Status tracking (active, resolved)
├─ Admin who created it
└─ Related order reference

conversations (5 columns)
├─ Message threads per rider
├─ Conversation title
└─ Timestamp tracking

messages (8 columns)
├─ Message content
├─ Sender identification
├─ Message type (normal, warning_notice)
└─ Conversation association

registration_approvals (8 columns)
├─ Approval workflow tracking
├─ Admin who approved/rejected
├─ Rejection reason (if applicable)
└─ Approval timestamp

license_update_requests (9 columns)
├─ Pending license photo updates
├─ Photo path comparison (old vs new)
├─ Review status and reviewer
└─ Rejection reason (if applicable)

audit_logs (7 columns)
├─ Admin action tracking
├─ Action type and target
├─ Additional details
└─ Timestamp

Indexes: 16 total for optimal query performance

================================================================================

Phone:              Philippine format (09XXXXXXXXX or +639XXXXXXXXX)
Password:           Min 8 chars, uppercase + lowercase + number
TIN:                Exactly 9 digits
License Number:     Alphanumeric + dashes, max 50 chars
License Photo:      JPG/PNG only, max 5 MB
Vehicle Type:       Enum (Motorcycle, Bicycle, Tricycle, Car/Van, Truck)
